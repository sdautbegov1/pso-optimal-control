# PSO Optimal Control

This repository contains a project on the application of Particle Swarm Optimization (PSO) to optimal control problems and PID controller tuning for dynamic systems.

The project focuses on two main approaches:

- direct optimization of the control signal over a finite time horizon
- PSO-based tuning of PID controller parameters in closed-loop control

The analysis includes first-order and second-order systems, with evaluation under different reference inputs and operating conditions.
